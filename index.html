Simulator

Interactive engineering demo — simulated data.

A display-test line like the machines I commission: parts pass a code reader, a servo test station and a reject diverter. It runs entirely in your browser.

  1. Press Reset, then Start, and watch parts flow.
  2. In the Fault injection panel, open the guard door or press the E-stop to see Hold and Abort.
  3. Acknowledge the alarms, then Clear and Reset to recover.

Simulation only. It does not connect to or control any equipment and is not a validated production or safety system. The state model is a simplified example in the style of S88/PackML.

// Abort and hold causes are evaluated every scan
IF #EStop OR #ServoFault THEN #State := ABORTING;
ELSIF (#GuardOpen OR #Jam OR #BinFull)
      AND #State = RUNNING THEN #State := HOLDING;
END_IF;
CASE #State OF
  IDLE:     IF #Cmd.Start AND #Auto THEN #State := STARTING; END_IF;
  STARTING: IF #SpeedAtSetpoint THEN #State := RUNNING; END_IF;
  HOLDING:  IF #ConveyorStopped THEN #State := HELD; END_IF;
  HELD:     IF #Cmd.Unhold AND NOT #HoldCause THEN #State := UNHOLDING; END_IF;
  ABORTED:  IF #Cmd.Clear AND #AllAcked THEN #State := CLEARING; END_IF;
  // ... RESETTING, STOPPING, UNHOLDING, CLEARING
END_CASE;
